# StyleAI – Smart Wardrobe & Outfit Assistant (MVP)

A personal project to explore UI design, front-end development and early-stage product building.  
This app is an MVP (not fully powered by AI yet) that lets users:

- Upload or scan clothing items  
- Browse wardrobe-based outfit suggestions (static for now)  
- Explore a shopping page with curated items  
- Navigate through a polished UI inspired by modern AI apps  

### ⚠️ Note (Honest Version)
This version does **not** include real AI yet.  
All suggestions, wardrobe detection, and matching logic are placeholders built to test UI, UX, and product flow.

The goal is to:
- Build a visually appealing MVP  
- Develop core app architecture  
- Eventually integrate ML/AI for outfit scoring & wardrobe recognition
